Bunker Bridge

Remote signing without remote trust. The Pocket Signer serves a bridge page that speaks NIP-46 — copy the bunker link into any bunker-aware client (on your phone, another computer, anywhere) and signing requests travel over Nostr relays to the device, where each one still requires a physical tap.

About the device Source

Features

NIP-46 nativeStandard bunker:// links — works with clients that support remote signers, no extension needed.
Sign from your phoneThe device stays plugged in at home; requests reach it over relays.
Same consent modelRemote or local, nothing signs without the on-device tap. Relay auth (kind 22242) can auto-sign if you enable it.
PSBT relayPaste a PSBT on the bridge page from any device — review and sign on the hardware.

How to use

  1. With the device plugged in, open http://10.77.7.1/bridge.
  2. Copy the bunker link.
  3. Paste it into any NIP-46-aware Nostr client to log in.
  4. Approve each signing request on the device screen.
