Browser extension

Signer Link

Presents window.nostr (NIP-07) to any Nostr web client and forwards every call to the Pocket Signer over its USB-C link. Plugged in = you can sign. Unplugged = you can't. The simplest security model there is.

Get it on GitHub About the device

Features

Works everywhereiris.to, snort.social, coracle.social — any client with NIP-07 login.
Nothing to trustThe extension holds no keys. It's a courier between the web page and the device screen.
Physical consentEvery signEvent renders on the device and waits for a SIGN / REJECT tap.
Multi-accountWhichever account is active on the device is the one the extension uses.

Install (Chrome / Brave / Arc)

  1. Clone or download the repository.
  2. Open chrome://extensions, enable Developer mode.
  3. Load unpacked → select the extension folder.
  4. Plug in the Pocket Signer, open a Nostr client, log in via extension.
